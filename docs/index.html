Four steps, repeated millions of times

03 — The central finding

Placement, not just magnitude

A homogeneous model fit to a layered medium's bulk-averaged properties can be biased in either direction — the sign depends on where the absorption sits, not only how much of it there is.

05 — Ten years in the making

Not a new project — a continuation

The same physical question, revisited with better tools.

2014 — Hochschule Aalen

A Master's thesis on scattering, rendered in C

Built custom C-language Zemax DLLs implementing Phong BRDF and two new bulk phase functions — Schlick and von Mises-Fisher — with importance-sampling formulas derived symbolically in Maple. Verified experimentally on a self-built gonioreflectometer using a 6-channel LED array.

2014 — Project EyeStream

The same LED array, a new purpose

The identical 6-channel array (Royal Blue, Cyan, Lime, Amber, Red, Deep Red) became the light source for an independent white-light generation system.

2024 — photon-transport-toolkit

The thesis's own claim, quantitatively re-tested

Implementing schlick_pdf() from scratch and testing it against Henyey-Greenstein: the 2014 claim — "similar, but faster" — holds at moderate anisotropy, and now has a number attached to where it stops holding: g≈0.85–0.9, up to 37σ deviation.

06 — How it's built

Validation-first, every step

01

Nothing assumed correct

Every claim is checked against an analytically known limit — Beer-Lambert, energy conservation, Fresnel reflectance — before being trusted.

02

τ-based boundary crossing

Remaining path length carries across internal layer boundaries in optical-depth units — the detail that makes layered media work correctly.

03

Real bugs, found and fixed

A missing specular-reflectance term, an unresolved multi-boundary case, a Fresnel sign flip — each caught by a test failing exactly as it should.

04

Say what wasn't verified

Formulas without an independently confirmed source are explicitly left out, not quietly assumed — a documented gap, not a hidden one.
